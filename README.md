# Cadastro aluno

Projeto desenvolvido em Python para cadastro de alunos.

## Funcionalidades

- cadastro de nomes
- cadastro de idade
- cadastro de curso
- exibição dos dados cadastrados

## Tecnologias

- Python
- Git
- GitHub

- ## Como rodar

1. Clone o repositório:
   `git clone https://github.com/FabioAnjos-dev/Cadastro_Aluno.git`
2. Entre na pasta:
   `cd Cadastro_Aluno`
3. Execute:
   `python Cadastro.py`
